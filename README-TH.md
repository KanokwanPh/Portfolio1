# เว็บไซต์ Portfolio ภาษาไทย — ฉบับปรับคำแปลครบทั้งเว็บ

แตก ZIP แล้วเปิด `index.html` หรืออัปโหลดไฟล์ทั้งหมดไปยังเว็บโฮสติ้ง โดยให้ `index.html`, `script.js`, `styles.css` และโฟลเดอร์ `photo` อยู่ระดับเดียวกัน

หากเปิดแล้วเห็นเวอร์ชันเดิม ให้กด Ctrl + F5 เว็บยังใช้ Tailwind CSS, Lucide และ Google Fonts ผ่านอินเทอร์เน็ตตามโครงสร้างเดิม

## คำแปลฉบับแก้ไข

แก้หัวข้อที่มีภาษาอังกฤษหลงเหลือจากการแปลบางส่วน ได้แก่ หัวข้อตำแหน่งที่สนใจ กิจกรรมและความสำเร็จ งานพี่เลี้ยงนักศึกษา และระบบอัตโนมัติ พร้อมปรับถ้อยคำในรายละเอียดผลงานทุกโครงการให้อ่านเป็นธรรมชาติ คงชื่อบุคคล ชื่อโครงการ ชื่อหลักสูตร และศัพท์เทคนิคที่เหมาะสม เช่น Frontend, UX/UI, API, SQL และ Test Case

## สิ่งที่ปรับ

- แก้ภาพกิจกรรมซ้ำ: ภาพปก 1 ภาพ และรูปย่อเฉพาะภาพที่เหลือ จำนวนจริงของแต่ละกิจกรรมคือ 3 / 3 / 4 / 3 ภาพ
- รายการภาพบนการ์ดและหน้าดูภาพใช้ข้อมูลชุดเดียวกัน ตัวเลขเปลี่ยนตามรายการจริง และนำภาพที่โหลดไม่สำเร็จออกจากการ์ด
- แปลข้อความหน้าเว็บ เมนู ปุ่ม คำอธิบาย ทักษะ และรายละเอียดผลงานทั้ง 6 โครงการเป็นไทย โดยคงชื่อเฉพาะและศัพท์เทคนิคที่เหมาะสมไว้
- แยกประสบการณ์ทำงานและการศึกษาเป็นคนละแถวเต็มความกว้าง ส่วนการศึกษาจัดการ์ดสองคอลัมน์บนจอใหญ่และหนึ่งคอลัมน์บนมือถือ
- ปรับการ์ด ระยะห่าง ขนาดข้อความ ฟอนต์ไทย และจุดเปลี่ยนเมนูสำหรับจอแคบ โดยรักษาโทนครีม–ม่วง การ์ดโค้ง และรูปแบบเว็บเดิม
- แก้ตัวเปิดเรซูเม่ให้ใช้ PDF จริง เพิ่มการใช้คีย์บอร์ดกับปุ่มภาพ และรองรับกรณีคัดลอกอีเมลอัตโนมัติไม่ได้

ภาพประกาศนียบัตร รูปทั้งหมด และ PDF เป็นไฟล์ต้นฉบับ ไม่ได้แปลหรือแก้ข้อความที่อยู่ภายในภาพหรือ PDF ข้อมูลบุคคล ผลงาน วันที่ เกรด และลิงก์เดิมยังอยู่ครบ

## เพิ่มหรือลบภาพกิจกรรม

1. ใส่รูปลงในโฟลเดอร์ `photo`
2. เปิด `index.html` แล้วค้นหา `class="surface-card activity-card"` ของกิจกรรมที่ต้องการ
3. แก้รายการ `data-gallery` เช่น `data-gallery="photo/usc.jpg, photo/usc2.jpg, photo/usc1.png"`
4. รูปแรกเป็นภาพปก ส่วนรูปถัดไปเป็นรูปย่อ สคริปต์จะสร้างรูปย่อและนับจำนวนใหม่เมื่อเปิดหน้าเว็บ ไม่ต้องใส่ภาพปกซ้ำ
5. ชื่อไฟล์และตัวพิมพ์ใหญ่–เล็กต้องตรงกับไฟล์จริง ใช้ชื่อไฟล์ที่ไม่มีเครื่องหมายจุลภาค

ชื่อกิจกรรมสำหรับหน้าดูภาพอยู่ที่ `data-gallery-title` และคำอธิบายอยู่ที่ `data-gallery-issuer` ส่วนรายละเอียดผลงานในหน้าต่างป๊อปอัปแก้ใน `projectDetails` ที่ไฟล์ `script.js`

## ผลการตรวจ

ตรวจโครงสร้าง HTML, ID, ลิงก์ภายในหน้า, เส้นทางไฟล์และไวยากรณ์ JavaScript แล้ว ผ่านการทดสอบโค้ดสำหรับภาพ 1/3/4 ภาพ การตัดภาพซ้ำ จำนวนในหน้าดูภาพ การเปิดรูปที่เลือก การวนภาพก่อนหน้า/ถัดไป การนำรูปที่โหลดไม่ได้ออกจนไม่มีรูปเหลือ และตัวเปิด PDF ตรวจว่าภาพและ PDF ตรงกับไฟล์ต้นฉบับทุกไฟล์

การตรวจครั้งนี้เป็นการตรวจไฟล์และทดสอบตรรกะ JavaScript ยังไม่ได้ทดสอบการแสดงผลจริงในเบราว์เซอร์หรือการเข้าถึงลิงก์ภายนอก
